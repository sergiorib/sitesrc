# Quickstart: Página de Histórico

**Feature**: `03-historico`  
**Status**: Concluído

## 1. Como Visualizar e Testar

1. **Executar o ambiente de desenvolvimento Astro**:
   ```bash
   npm run dev
   ```
2. **Acessar a rota SPA de Histórico**:
   Abra o navegador em `http://localhost:4321/spa/historico` (ou navegue através do menu lateral da SPA).
3. **Validação de Conformidade**:
   - Verificar se o título "Histórico Profissional" é renderizado em Barlow Condensed 32px bold.
   - Verificar se o card da Experiência 1 exibe a logo com altura de 100px.
   - Verificar se as badges informativas e o bloco de tech stack com border-radius de 16px são exibidos corretamente.
